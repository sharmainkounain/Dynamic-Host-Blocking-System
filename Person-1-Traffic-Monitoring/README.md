# Person 1 – TCP Traffic Monitoring

This folder contains the TCP traffic monitoring and packet capture components of the Dynamic Host Blocking System.

## Files

- `tcp_rate_monitor.py` – Analyses TCP SYN packet rates.
- `tcp_rate_results.txt` – Sample monitoring output.
- `syn_packets.csv` – Extracted SYN packet information.
- `tcp_capture.pcapng` – Wireshark packet capture.

## Tools

- Python
- Wireshark
- Packet capture analysis
