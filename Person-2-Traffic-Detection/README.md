# Person 2 – Traffic Detection

This folder contains the traffic analysis and suspicious host detection components of the Dynamic Host Blocking System.

## Components

- `traffic_analyzer.py` – Reads and analyses TCP traffic from the CSV dataset.
- `detector.py` – Identifies hosts exceeding the configured SYN threshold.
- `blocklist.py` – Exports suspicious IP candidates to JSON.
- `logger.py` – Records detection results.
- `main.py` – Runs the traffic detection pipeline.
- `config.py` – Defines detection thresholds and file paths.

## Detection Configuration

The detection module uses the following configuration:

| Parameter | Value |
|---|---|
| SYN_THRESHOLD | 3 |
| TIME_WINDOW_SECONDS | 10 |
| Detection condition | SYN count greater than threshold |

A host is classified as suspicious when its TCP SYN packet count exceeds the configured threshold within an observation window.

## Data and Results

- `data/traffic.csv` – Input traffic dataset.
- `output/suspicious_ips.json` – Contains suspicious IP candidates.
- `output/detection.log` – Stores detection results.

The JSON output contains detection candidates, not confirmation of malicious activity or proof that a firewall block has been applied.

## Dependencies

The project uses Python and pandas.

Install the required dependency using:

```bash
pip install -r requirements.txt
```

## Running the Program

Run the following command from the `Person-2-Traffic-Detection` directory:

```bash
python -m src.main
```

The program reads the configured CSV dataset, analyses TCP SYN packets, applies the detection threshold, and generates the JSON output and detection log.

## Integration with the SDN Controller

The suspicious IP candidates generated by this module can be provided to the SDN controller developed by Person 3.

The current project represents this handoff as a manual step. Automatic communication between the detection module and the SDN controller has not yet been demonstrated.
